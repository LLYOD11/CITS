# CITS (JXON)

## Overview
CITS/JXON is a multi-tenant IT service management platform designed for high-velocity support teams. It combines intelligent ticket handling, tiered collaboration, real-time incident coordination, and a full customer portal.

## Key Features
Core Ticketing
•  Multi-queue views (All, Open, Awaiting Info, On Hold, Pending, Resolved, Closed, Assigned to Me)
•  Priority levels P1–P5 with visual indicators and SLA timers + breach-risk flags
•  Category filters (Infrastructure, Security, Application, Network, Database)
•  Multi-select ticket banner with conversation history, internal notes, and status actions
•  Linked INC / RITM references, tags, assets, and company context
Tiered Collaboration
•  Role-based access: Customer Portal (external) vs Staff Workspace (internal)
•  Support tiers:
	•  T1 – Service Desk
	•  T2 – Technical Support
	•  T3 – SME / Experts
	•  T4 – Vendor / Management
•  Seamless escalation and coordinated workflows across tiers
War Room
•  Dedicated P1 incident command center
•  Live incident list, response team roster, and real-time chat
Intelligence & Automation
•  Proactive monitoring & auto-ticket generation from simulated alerts
•  Automation Engine (rule-based assignment, escalation, notifications)
•  Auto-resolution for routine/metric-based cases
•  Knowledge Base suggestions and duplicate detection
•  Sentiment indicators on conversations
Additional Modules
•  Customer Portal – create incidents, track SLA progress, browse KB
•  Asset Management – track laptops, servers, network devices, etc.
•  Knowledge Base – articles, FAQs, how-tos, policies, known errors
•  Company Management – full multi-tenant support
•  Email Integration – auto-create/update tickets from mailbox
•  REST API Console – simulated endpoints for external integrations
•  Audit Logs – complete action trail for compliance
•  Admin Panel – users, companies, SLA configuration, alert rules, metrics
UX & Platform
•  Dark modern UI with command palette, global search, notifications, and toasts
•  SSO support (Google, Microsoft, Okta) + email login
•  Dashboard with volume, SLA compliance by tier, category breakdown, and resolution-time charts
